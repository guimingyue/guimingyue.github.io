从 ChatGPT 2022 年 11 月推出，到现在已经过去 4 年了，近两年 AI 逐渐从一个更好的搜索引擎演变成了 Agent，进入了日常工作中。从 2025 年开始接触 Agent，到现在工作中深入使用 Agent，这一年多以来变化太大了，AI Agent 已经重塑了工作的模式。这篇文章主要总结目前如何在工作中使用 Agent 以及当前的一些观察。

# 积极拥抱 AI Agent
在日常工作中主要使用两类 Agent：Coding Agent 和 Work Agent，但是这两类的界限并没有那么大，Work Agent 其实就是在 Coding Agent 之上又增加了一些工具能力，所以下文统称为 Agent。

## 用 AI 来干什么
相比于去年，今年最大的变化就是通过 AI Agent 将 AI 真正的融入到了日常工作中，而不再是搜索引擎的替代品了。在日常工作中，主要有两大使用场景：
* AI Coding，使用 Agent 来编码实现产品需求，
* 排查问题，使用 Agent 排查线上以及客户提过来的问题。

### AI Coding 

去年，听到某些人谈论到现在已经不会手写一行代码的时候，有些惊讶，怎么可能把写代码的工作完全交给 AI 呢？无法理解，后来接触的越多，越发现这就是大趋势，无法打败就加入。

深度使用 AI Coding 之后，会发现 AI Agent 写出来的代码，对于小需求还好，能够把某一个点的问题给解决掉，但是当项目比较复杂时，有时候虽然基本功能能完成，但是会有比较多的问题，比如过度设计，比如在需要考虑性能的场景，性能问题没考虑到，会增加本来可以不用查数据库的操作。最近在给一个网关产品增加一个权限拦截的操作，主要分为两个部分，控制面和数据面，控制面是面向管理员设置权限的管理后台，而数据面就是接口调用时的权限校验的拦截。 AI 实现了基本的功能，但是深入去看代码时，遇到的问题主要有以下几个方面：

* 控制面使用列表接口代替单个查询，也就是说在某个功能点需要查询一条记录时，AI 使用列表接口查询出来后，再使用 ID 进行过滤，最后得到预期的数据记录，但是这种实现是有 bug 的，万一列表接口后面有分页
* 数据面使用本地缓存，而不是 redis 这样的缓存服务。

所以 AI Coding 的代码产出量快且大，但是产出的代码如何在线上能够稳定的运行也是一个需要重点关注的问题。对于用户规模比较大的服务或者比较关键的服务，例如网关，还是需要人来 review 整体的代码，确保代码在运行时，不会偏离期望。目前的体感是，如果考虑代码的质量保障，AI Coding 的效率不一定会比古法编程快多少，因为古法编程敲出来的代码是经过人确认的，代码在什么时候起作用，是经过编写者的设计的，这么看来当前 AI Coding 只是把质量保障全部后置了。当然，如果 AI 继续发展，后续可能也不需要人类来 review 代码来，到那个时候，软件工程师这个职业可能就要消失了，或者也可以说是人人都是软件工程师。

### 排查问题

不错，虽然现在大家谈论得比较多的是 Vibe Coding，但是对于代码工程师来说，编码只是日常工作中一部分工作，还有很大一部分时间是在排查和解决问题，相比于 Coding，排查和解决问题这块，我觉得 AI 提效更多。以前排查问题，先根据一些参数信息去查日志，然后对照着日志去分析代码，现在轻松多了，遇到反馈过来的问题，先把相关的参数给到 Agent，然后就可以去干其他事情了。当然排查问题，还需要一些排查问题的工具和 SKILL，包括数据的查询，日志的查询和配置的查询，再结合代码仓库，Agent 在参数给定的正确的情况下，基本上可以把问题排查得七七八八。所以 Context is All you Need.

所以，在日常工作中，先把自己在脑海中已经有的工作流梳理出来，沉淀到 SKILL 中，下一次遇到问题时，就先用 Agent 来实现，再一步一步的完善这个 SKILL，这样就可以通过 AI Agent 来帮助自己提升效率，这不是就与年初大家都在提的蒸馏的概念吗？

# 使用 AI Agent 的误区

AI Agent 确实对个人提效比较大，但是组织内效率的提升并不完全取决于个人效率的提升，目前组织内期望通过 AI 来提效其实与十多年前组织内期望通过数字化来提效比较像，数字化提效的逻辑是通过将组织内的业务在线化，组织内的成员通过在线协作，信息透明等方式提高效率。目前 AI 给个人提效比较明显，但是组织维度是否提效取决于组织内的制度，文化等。

# 总结

AI 是一种工具，是工作中个人提效的利器，替代人来还为时尚早，但是 AI 再继续往后发展，后面是否替代人，就不知道会怎么样了。至少，在现在大家应该积极的去拥抱 AI，在工作和生活的各个场景中使用 AI，知道 AI 能做什么不能做什么，借助 AI 来提升个人的效率和改善生活。
